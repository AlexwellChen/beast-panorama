# Beast Panorama v0.3.0 — 鼠标与头追协同、画面缩放、原生 1200p

面向 Apple Silicon 的 macOS 360° 全景播放器预览版。此版本保留现有的软件 3DoF 头追，并改进观看方向、画面大小和眼镜输出设置。

## 下载与安装

**推荐下载 `Beast-Panorama-0.3.0-arm64-with-sdk.dmg`**：内置 VITURE XR Glasses SDK 2.4.0，无需另行下载或选择 SDK。打开 DMG，将应用拖入 Applications，连接 Beast，打开本地 2:1 全景视频或图片；正视后按 R 居中。

要求 Apple Silicon、macOS 13 或更新版本。`Beast-Panorama-0.3.0-arm64.dmg` 是可选的 SDK-free 版本，鼠标观看可直接使用，头追需要外部 SDK。两种 DMG 均附 SHA-256 校验文件。不包含 samples、测试视频或厂商头文件。

## 本次更新

### 鼠标拖动与头追同时使用

- 开启头追后，也能用鼠标拖动调整当前观看方向，随后继续转头环视。
- 修复朝侧面看时，上下拖动错误地变成画面歪转的问题：俯仰现在绕当前相机的左右轴旋转。
- R 居中会同时清除鼠标偏移和头部参考方向。
- 增加多个头部朝向的旋转组合回归测试。

### 保留头追的画面大小调节

- 「眼镜显示设置 → 画面缩放」：40%–200%；100% 铺满画布，超过 100% 放大并裁切边缘。
- 「景物放大」：垂直视场角扩大到 20°–90°；向右拖动让景物显得更大。
- 「放大观看」：一键设置 100% 画面缩放、45° 视场角。
- 缩放和视场角设置会保存。以上调节不关闭头追，也不改变眼镜光学焦距或真实观看距离。

### 真正的眼镜输出分辨率选择

- 设置新增 1920×1080 / 1920×1200 输出选择，切换时均使用 60Hz。
- 使用 SDK 的 bypass 显示接口，保留播放器的软件头追。
- 同时核对 SDK 模式读回值、macOS 像素尺寸和刷新率；有匹配模式时请求 macOS 切换。
- HiDPI 桌面缩放不被当作原生 1200p 成功；未确认生效时尝试恢复之前的模式，并显示结果。
- **本机 Beast + Apple Silicon + SDK 2.4.0 已实测通过 1920×1200 / 60Hz，SDK 与 macOS 均验证成功，头追连接保持开启。** 这不代表所有固件与连接方式均已验证。

## 当前限制

- 分辨率选择当前固定使用 60Hz；重新连接仍从 1080p60 启动，需要在设置中重新选择 1200p。
- 120Hz 选项仍为实验性功能，本次没有新增高刷新率成功实测；校验失败会回退。刷新率切换可能回到 1080p。
- HDR 仍为 SDR 预览，不支持立体视频；部分 SDK 调用和媒体检查仍在主线程。
- 原生 1200p 已验证，物理黑边与佩戴观感仍取决于固件、光学可视范围和佩戴位置。
- 应用使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。
